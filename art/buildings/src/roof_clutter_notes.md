# Roof clutter preparation

Owns seven family-neutral phase-2 roof props only. Built-in image generation supplies one standalone three-quarter concept per prop. The Blender authoring script preserves each original minimal mesh; texture GLBs use separate, non-overlapping 0-1 UV layouts for later root-owned Rodin baking and neutral-atlas repacking. No Rodin requests or ledger changes are made by this agent.

All model geometry uses metres, +Z up, -Y front, ground-centre origins. Billboard poster face sizes are independent from their frames and supports; sign cards will be provided by the sign-page pipeline.
